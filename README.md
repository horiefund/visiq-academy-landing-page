# VISIQ Academy Codex Materials

This folder is a starter pack for building the VISIQ Academy website in Codex.

## Folder Structure
- `01_brand_assets/` : official logo and nameplate / badge reference images
- `02_core_docs/` : core documents and PDFs
- `03_design_references/` : pamphlet style references
- `04_web_copy/` : approved core copy for website use
- `05_notes/` : design and implementation notes for Codex

## Recommended First Prompt for Codex
Use the materials in this folder to propose the information architecture and then build a trustworthy, elegant homepage for VISIQ Academy. The site should target elementary school parents and guide them toward a free trial inquiry. Keep the design white-based, refined, and trustworthy, with slight warmth from child-friendly illustrations. Do not hardcode pricing or schedule information.
