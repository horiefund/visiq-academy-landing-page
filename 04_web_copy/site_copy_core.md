# VISIQ Academy Web Copy Core

## Core Message
家庭環境に左右されない学びの環境をつくる。

## Tagline
学びを“消費”から“資産”へ。

## What VISIQ Academy Is
VISIQ Academyは、子どもが自ら学び続ける力を育てる教育プログラムです。
一般的な塾のように「教わること」を中心にするのではなく、
自宅での実行と教室での振り返りを通して、学びを自分で回す力を育てます。

## Key Service Structure
- スタサプ × AI × 作戦会議 × 自走力
- 自宅でDo、教室でPlan / Check / Act
- タイピングは思考を外に出す入口
- AIは答えを写す道具ではなく、思考のパートナー

## Important Brand Rules
- ランクは順位ではなく、成長のしるし
- 比べるのは他人ではなく、昨日の自分
- 料金・開催日時・申込方法などの可変情報は本体パンフレットや固定ページに焼き込まない

## Suitable Families
- 「勉強しなさい」と言う回数を減らしたい
- 教材はあるのに、家でうまく回らない
- 受け身ではなく、自分で学ぶ力を育てたい
- 将来につながる学び方を、小学生のうちから身につけたい

## Early Changes Parents Can Notice
- 自分から机に向かう回数が増える
- 目標を立てる習慣が出てくる
- 振り返りや言語化が少しずつできるようになる
- 勉強を「やらされるもの」ではなく「自分で進めるもの」として捉え始める
